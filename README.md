# Campus Portal

A University Campus Portal web application (Midterm / UTS project for Web and
Mobile Application Development). This stage is a front-end only app that uses
hardcoded mock data — no backend, no database, no real authentication.

## Tech stack

- React (Vite)
- React Router (`react-router-dom`)
- Plain CSS (no CSS framework)
- React Context API for global state (added in Phase 4)

## Project status

- [x] Phase 1 — Foundation & core layout
- [ ] Phase 2 — Authentication & dashboard
- [ ] Phase 3 — Course registration form
- [ ] Phase 4 — State management, responsiveness & polish

## Getting started

```bash
npm install
npm run dev
```

Other scripts:

```bash
npm run build     # production build
npm run preview   # preview the production build
npm run lint      # oxlint
```
